# Evidence Review

## Evidence Set

Use the smallest set that proves the brief:

1. The actual source image available to the client.
2. A `capture_viewport` image framed to match the source view.
3. Front and side/profile inspection renders for stable shape comparison.
4. Additional views or inspectors only for declared criteria.

Do not score from text alone when image evidence is available. Do not use surface detail as evidence that silhouette or proportions are correct.

## Scorecard

Score each applicable criterion from 1 to 5 and attach concrete evidence:

- `silhouette_match`
- `proportion_match`
- `landmark_placement`
- `form_continuity`
- `surface_match`
- `constraint_compliance`
- `evidence_ready`

For every score, provide:

- criterion;
- score;
- compared view or inspector;
- observable finding;
- targeted repair action.

## Anchors

- `1`: Major contradiction; the subject or structure reads incorrectly.
- `2`: Multiple high-impact deviations.
- `3`: Recognizable but materially inaccurate.
- `4`: Meets the declared brief with only minor deviations.
- `5`: Strong reference agreement in the available evidence.

Use the planner's quality floor, normally 4. Do not average away a failed criterion; each applicable criterion must pass.

Use ordinal scores when the source does not support precise geometric error bounds. Add pixel, percentage, angle, or parameter tolerances only when the user supplied them or they were measured reproducibly from readable image evidence. Never invent precision to make a gate look objective.

## Review Order

1. Silhouette and negative spaces.
2. Primary-mass ratios and contact points.
3. Landmark position and alignment.
4. Form transitions and attachment quality.
5. Surface cues.
6. Negative constraints and evidence completeness.

Capture the same views after repair. A changed angle invalidates direct before/after comparison unless the source framing also changed.
